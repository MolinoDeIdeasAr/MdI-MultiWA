TAREA: CORREGIR NOTIFICACIÓN "INFO"

Lee primero instrucciones.txt y respeta todas sus reglas.

OBJETIVO

Cuando un contacto responde "INFO", el sistema debe:

1. Recibir el mensaje "INFO".
2. Detectar la intención "solicitud_info".
3. Enviar la respuesta automática al contacto.
4. Notificar al celular del usuario logueado.
5. La notificación debe enviarse utilizando el mecanismo existente de notification-service.js.

DIAGNÓSTICO PREVIO

Se realizó una auditoría del código y se encontró lo siguiente:

- core/ai/ai-rules.js detecta correctamente "INFO".
- La intención generada es "solicitud_info".
- services/conversation-context.js establece correctamente:
  
  debeNotificarAsesor = true

  cuando la intención es "solicitud_info".

- services/notification-service.js contiene la función:
  
  notificationService.notificar(context)

- notification-service.js utiliza context.userId para identificar al usuario y obtener su número de notificación.
- notification-service.js utiliza context.client para realizar el envío.
- El problema detectado es que services/ai-flow.js no llama a notificationService.notificar(context) después de enviar la respuesta automática.

TRABAJO

1. Verifica nuevamente este diagnóstico en el código actual antes de modificar nada.

2. Si el diagnóstico es correcto, modifica ÚNICAMENTE:

services/ai-flow.js

3. Importa notification-service.js utilizando la ruta correcta según la ubicación real del archivo.

4. Después de:

await this.enviarRespuesta(context);

debe ejecutarse:

if (context.debeNotificarAsesor) {
    await notificationService.notificar(context);
}

5. La notificación solamente debe ejecutarse cuando:
   
context.debeNotificarAsesor === true
